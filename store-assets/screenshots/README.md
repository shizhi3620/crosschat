## 合规要点

- 全部为**真实产品渲染**：Chrome for Testing 155.0.8059.84 加载实际扩展代码，走真实分级路由 / demo-engine / PII / 计量管线，非设计稿。
- 看板数据为确定性种子的**演示数据**（Northwind 虚构店铺），截图中界面标注「演示模式」。
- 不出现 TikTok / Shopee / Amazon / Gmail 等任何平台商标或名称（plan rev.2 §8）；平台真实选择器只存在于扩展代码内，不作为商店素材。
- 不含买家真实消息或个人信息；演示邮箱均为 example.com 保留域名。
- 不出现「自动回复」类措辞；所有画面均强调草稿由人工点击发送。
- 测试专用 host（http://127.0.0.1:*）仅存在于 scratch 测试副本，曾出现在 options 页第 5 候选截图中，该截图已剔除（options 含平台预设名称，不入选）。

## 复现

本地截图脚本 `c2b/shoot.mjs`（不随包发布）：复制正式扩展到临时 `ext-shoot/` 后才打补丁（host_permissions 加本地 host、telemetry endpoint 指向本地 sink G-SHOOT00001）；**补丁从不进入本目录正式代码**。sips 由 2560×1600（DSF 2）降采样到 1280×800。
