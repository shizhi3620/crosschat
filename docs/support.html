常见问题

1. 收费吗？

上线验证期内扩展完全免费、无功能限制。BYOK 模式下模型调用按你的火山方舟账号实际用量，由你直接与火山引擎结算；离线演示模式不产生任何费用。

2. 必须有 API Key 才能用吗？

不是。首次安装可直接进入内置离线演示（4 个场景、不连外网）跑通全部流程。需要真实草拟时再配置 BYOK：在火山引擎控制台开通火山方舟、创建 API Key，粘贴到扩展设置页即可，Key 只存在本机。

3. 它会自动回复买家吗？

永远不会。扩展只把草稿填入页面回复框，发送按钮由你本人点击；它不调用任何平台发送接口、不定时发消息。

4. 支持哪些网站？

适用于你明确授权的跨境卖家后台、卖家中心、客服 CRM 与网页邮箱，也可以添加任意自定义域名。默认不读取任何网页——只有你在设置里添加并完成浏览器授权的站点才会注入助手，移除后立即停止。

5. 我的 API Key 安全吗？

Key 保存在浏览器本地存储中，模型请求从你的浏览器直连火山方舟，不经过扩展作者的任何服务器。你可以随时在设置页删除 Key。

6. 匿名统计包含什么？怎么关闭？

v1.0.1 起统计通道已完全停用：扩展不发出任何统计请求（v1.0.0 的 Google Analytics 直连方式已移除，扩展包内不再包含任何统计密钥）。代码中仅保留 4 类计数事件（安装、每日活跃、草拟、采纳）与 3 个枚举字段（模型级别 L0/L1/L2、平台大类、运行模式）的白名单定义，不含消息正文或个人信息；将来恢复统计时只会发往自建的匿名中继，且设置页开关默认关闭。详见隐私政策。

7. 怎么彻底删除我的数据？

在看板点「清空计量数据」、设置页删除 Key 与站点；卸载扩展时浏览器会清除全部本地数据。

8. 中国大陆能用吗？访问不了商店怎么办？

安装后的日常使用不依赖境外网络：BYOK 直连火山方舟国内端点，离线演示完全本地运行。安装本身有三种途径：①Chrome Web Store（需能访问商店）；②Edge（可在设置中允许其他应用商店扩展后从商店安装，Edge 独立商店版提交中）；③访问不了商店时，可离线下载安装包，以开发者模式「加载已解压的扩展程序」安装——完整图文步骤见安装教程：离线安装。

9. 支持 Edge / Firefox 吗？

v1.0.1 要求 Chrome / Edge 110+。Edge 加载项商店版本正在提交审核，审核期间可按安装教程用「允许其他商店」或开发者模式两种方式在 Edge 上使用；Firefox 暂无时间表。

10. AI 草稿出错或合规检查漏判怎么办？

草稿必须经你审核后手动发送，你对最终内容负责。合规提示是辅助手段，不保证覆盖全部风险。发现质量问题欢迎把场景（脱敏后）反馈给我们。

11. 发现安全漏洞怎么报告？

请邮件 crosschat.app@gmail.com 描述复现步骤，请不要在公开渠道发布漏洞细节，我们会在 72 小时内确认。

安装与配置

完整图文版（含 Edge 与国内离线安装、火山方舟开通三步、401/403/404 排错）见 安装与配置教程。简版：

  1. 在 Chrome Web Store 页面点击「添加至 Chrome」并确认；访问不了商店就走离线安装。
  2. 首启引导页：先用内置演示 30 秒熟悉流程，无需 Key、不连外网。
  3. 在「管理我的客服站点」里添加你要使用的站点并逐个授权（按需授权，可随时移除）。
  4. （可选）在火山引擎控制台开通火山方舟、创建 API Key，填入设置页 BYOK 区，先点「测试连接（不保存）」再保存；没有 Key 可继续使用演示模式。
  5. 打开你的客服网页，选中一条买家消息，点工具栏里的跨海聊图标即可开始。

卸载

地址栏输入 chrome://extensions → 找到跨海聊 CrossChat → 移除。移除后本地配置、Key、历史与计量数据一并清除。

Frequently asked questions

1. What does it cost?

Nothing during the launch validation period — no feature limits. In BYOK mode, model calls are billed by Volcengine directly against your own account and usage; the offline demo mode makes no paid calls at all.

2. Do I need an API key?

No. After install you can run the built-in offline demo (four scenarios, no network) through the complete pipeline. Configure BYOK later when you want real drafts: open Volcengine Ark in the Volcengine console, create an API key, and paste it into the options page. The key stays on your machine.

3. Does it auto-reply to buyers?

Never. It only fills a draft into the page's reply box; you click send yourself. It calls no platform messaging API and never schedules messages.

4. Which websites are supported?

Cross-border seller backends, seller centers, customer-service CRMs and webmail that you explicitly authorize, plus any custom domain you add. Nothing is read by default: the assistant is injected only on sites you add and grant, and injection stops as soon as you remove one.

5. Is my API key safe?

It lives in the browser's local storage, and model requests go directly from your browser to Volcengine Ark — through no server of ours. You can remove it in the options page at any time.

6. What is in the anonymous statistics? How do I opt out?

Since v1.0.1 the statistics channel is fully disabled: the extension sends no analytics requests at all. The v1.0.0 direct Google Analytics transport has been removed and the package no longer contains any analytics secret. The code only retains the whitelist definition for four counter events (install, daily active, draft generated, draft adopted) with three enumerated fields (model tier L0/L1/L2, coarse platform class, run mode) — never message text or personal information. If statistics are re-enabled in a future release they will go only to our own anonymous relay, with the options toggle defaulting to off. See the Privacy Policy.

7. How do I delete all my data?

Use "Clear metering data" on the dashboard and remove your key/sites in options; uninstalling the extension makes the browser remove all local data.

8. Does it work in mainland China? What if the store won't load?

Day-to-day use after installation needs no overseas network: BYOK calls go straight to Volcengine's domestic endpoint, and the demo runs entirely locally. There are three install paths: (1) the Chrome Web Store (store must be reachable); (2) Edge — allow extensions from other stores in Edge settings, or wait for the dedicated Edge Add-ons listing (under review); (3) if the store is unreachable, download the package and load it as an unpacked extension in developer mode. Full walkthrough: Install guide: offline install.

9. Edge or Firefox?

v1.0.1 works on Chrome/Edge 110+. The Edge Add-ons submission is under review; meanwhile the install guide explains both the “allow other stores” route and developer-mode loading in Edge. Firefox has no timeline yet.

10. What if a draft is wrong or a risky draft slips past the checks?

Drafts are sent only after your manual review, so you remain responsible for final content. Compliance warnings are assistance, not a guarantee. Please send us (redacted) examples so the product can improve.

11. How do I report a security issue?

Email reproduction steps to crosschat.app@gmail.com and please do not post vulnerability details publicly; we acknowledge within 72 hours.

Install & setup

The full illustrated guide (including Edge, offline install behind the GFW, the three-step Ark setup, and 401/403/404 troubleshooting) is on the Install & setup guide. Short version:

  1. Click "Add to Chrome" on the Chrome Web Store page; if the store is unreachable, use the offline path.
  2. On the first-run page, spend 30 seconds with the built-in demo — no key, no network.
  3. Add the sites you use under "Manage my customer-service sites" and grant them one by one (grants are optional and revocable).
  4. (Optional) Enable Volcengine Ark in the Volcengine console, create an API key, paste it into the BYOK section, and click "Test connection" (never saves) before saving; without a key you can keep using the demo.
  5. Open your customer-service page, select a buyer message, and click the CrossChat toolbar icon.

Uninstall

Go to chrome://extensions → find CrossChat → Remove. Removing it also clears local settings, keys, history and metering data.
