1. 产品做什么（单一用途）

本扩展只有一个用途：在你自己的客服网页里，帮你草拟买家消息回复。它捕获你主动选中的买家消息，进行翻译、知识库匹配和草拟，把草稿填入页面已有的回复框。扩展从不点击发送、不定时发消息、不执行任何账号操作——每条回复都由你本人审核并通过平台原生按钮发出。

2. 只存在你设备上的数据

以下数据通过浏览器的本地存储（chrome.storage.local）保存，不上传到我们的任何服务器，卸载扩展时由浏览器一并清除：

扩展不需要注册账号，不收集你的姓名、邮箱（自愿登记的除外，且见上条）、电话或付款信息。

3. 扩展发起的网络请求（完整清单）

3.1 模型请求：直发服务商，不经过我们

仅当你配置了 BYOK（自带 Key）并主动点「翻译 / 草拟回复」时，浏览器会把买家消息文本和相关知识库片段直接发送到火山方舟（Volcengine Ark，ark.cn-beijing.volces.com，位于中国大陆），使用的是你自己的 API Key。请求不经过、不中转、不留存在扩展作者的任何服务器上。该处理受火山引擎/字节跳动的隐私政策约束。在离线演示模式下不会发起任何模型请求。买家消息中的邮箱、电话、银行卡号、地址等会在发送前自动脱敏，并在你采纳草稿时在本机还原。

3.2 匿名使用统计：Google Analytics 4（默认开启，可关闭）

扩展通过 Google Analytics Measurement Protocol v2 上报少量匿名计数，用于判断产品是否有人用、是否有用。详见第 4 节。

3.3 不会发生的请求

  • 扩展不读取你访问的网页：助手只在你明确添加并授权的站点上注入，移除授权立即停止注入；
  • 不请求浏览器 Cookie、不同步账号、不收集浏览历史；
  • 内置知识库种子文件是扩展包内的本地文件，不从网络下载。

Privacy Policy

CrossChat browser extension v1.0.0 · Effective: 2026-10-16

In one sentence: your buyer messages, API key and store data stay on your own device; we collect no message content, run no ads, and never sell data. Anonymous usage counts can be switched off in one click.
What it doesLocal dataNetwork requests Usage statsYour rightsContact

1. What the extension does (single purpose)

The extension has one purpose: helping you draft replies to buyer messages inside your own customer-service web pages. It captures a buyer message you actively select, translates it, matches it against your knowledge base, and drafts a reply which it fills into the page's existing reply box. It never clicks send, never schedules messages, and performs no actions in your accounts — every reply is reviewed and sent manually by you, using the platform's own controls.

2. Data stored only on your device

The data below is kept in the browser's local storage (chrome.storage.local). It is never uploaded to any server of ours and is removed by the browser when you uninstall the extension:

DataContentsHow to delete
SettingsRun mode, authorized-site list, model parameters, unit-price configReset in options, or uninstall

Knowledge baseYour own after-sales FAQ (seeded once from a file packaged inside the extension; fully editable)Edit/clear in options, or uninstall

The extension does not require an account and does not collect your name, email (apart from the voluntary local-only registration above), phone number, or payment information.

3. Every network request the extension makes

3.1 Model requests — sent directly to the provider, never through us

Only when you have configured BYOK with your own key and you actively click Translate/Draft, the browser sends the buyer message and relevant knowledge-base snippets directly to Volcengine Ark (ark.cn-beijing.volces.com, hosted in mainland China) using your own API key. These requests do not pass through, and are not stored on, any server operated by the extension developer. They are subject to Volcengine/ByteDance's own privacy policy. The offline demo mode makes no model requests. Email addresses, phone numbers, card numbers and postal addresses detected in buyer messages are masked before sending and restored locally when you adopt a draft.

3.2 Anonymous usage statistics — Google Analytics 4 (on by default, opt-out available)

A small set of anonymous counters is sent via Google Analytics Measurement Protocol v2, solely to assess whether the product is used and useful. See section 4.

3.3 Requests that never happen

  • The extension does not read the web pages you visit: the assistant is injected only on sites you explicitly add and authorize, and injection stops immediately when you remove a site;
  • It does not request browser cookies, account sync, or browsing history;
  • The bundled knowledge-base seed is a local file inside the extension package, never downloaded.

4. Exactly what the usage statistics contain

Events are restricted by a code-level whitelist to the 4 events and 3 enumerated fields below; any other field is dropped before sending:

EventMeaningParameters
installFirst install (counter)none
daily_activeAt most one per random client per UTC daynone
draft_generatedA draft was generatedlevel: L0/L1/L2 (model tier); platform_class: tiktok/shopee/amazon/gmail/other (coarse hostname classification only); mode: demo/byok/hosted
draft_adoptedA draft was adopted into the reply box
  • Never included: message text, translations, knowledge-base content, personal data, full URLs, page titles, or API keys.
  • The client ID is a random UUID generated at install, linked to no identity. We set no cookies (Measurement Protocol does not rely on page cookies). Google, as the receiving party, may see the request source IP under its standard data processing; see also the Google Privacy Policy.
  • To opt out: uncheck "Send anonymous usage statistics" in section 7 of the options page. After opt-out no statistics requests are made.
  • The Measurement Protocol secret packaged in the extension can only write these events to our analytics property; it cannot read data.

5. This website and the store listing

This site is hosted on GitHub Pages; GitHub may log page requests under its privacy statement. The site itself sets no cookies, runs no analytics scripts, and loads no third-party tracking resources. The extension is distributed through the Chrome Web Store, where installs and reviews are covered by the Google Privacy Policy.

6. Your choices and rights

  • Opt out of statistics: one toggle in the options page, effective immediately;
  • Delete data: clear metering data on the dashboard, remove your key and sites in options, or simply uninstall the extension (all local data is removed);
  • Access requests / complaints: email the address below; we respond within 30 days;
  • The extension is not directed to children under 13 and does not knowingly collect children's information.
